# API

`GET /api/health`, `GET /api/config`, `POST /api/face/analyze`, `POST /api/search`, `POST /api/search/{search_id}/select`, `POST /api/fingerprint/create`, `POST /api/blockchain/record`, `GET /api/blockchain/record/{fingerprint}`, `POST /api/blockchain/verify`, and `POST /api/demo/tamper` are implemented. Interactive schemas are at `/docs`.
